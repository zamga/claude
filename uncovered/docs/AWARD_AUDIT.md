# Uncovered: award audit

Scored the way the juries score: the site jury on design, usability, creativity and content (weighted 40/30/20/10), the developer jury on semantics, animation, accessibility, performance, responsiveness and markup. Scores are out of 10, measured where a measure exists. This audit covers the site and the research engine.

## What a technical jury would ask of the engine

| Question                           | Answer                                                                                                                                                                                                                                                                                                   |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Can the model invent a number?     | Not one that reaches a report. A figure is recorded only if its number, as printed, sits inside a quotation that occurs word for word in the document the engine read. The gate then checks every number in every sentence against the passages that sentence cites, and withholds what it cannot trace. |
| Can a document steer the engine?   | It reads only through the engine's tools, and fetches only addresses that appeared in search results, in the request or in a page already read, so it cannot put anything of its own into an address. Public addresses only, checked on the connection itself; robots.txt honoured.                      |
| Who can spend money, and how much? | Access codes, runs per address per hour, runs at once and a time limit per run. Every run keeps an audit of documents, quotations, tokens, searches and cost.                                                                                                                                            |
| Has it run for real?               | Not yet. It is tested end to end with a scripted model client and a test filing, through the API, the progress stream and the browser. The first live runs are fix 1.                                                                                                                                    |

| #   | Fix                                                                                                                                                                                                                                           | Why                                                                                          | Impact                    |

| 4   | LCP within budget on every page: metric-matched fallback fonts, a smaller first-screen font subset, less script before the first paint                                                                                                        | The largest text paints late in the simulated slow-4G profile                                | Performance               |
| 5   | Durable runs: a job queue with resumable stages, and pdf.js in a worker thread                                                                                                                                                                | A restart fails the runs in progress; a very large PDF slows other requests while it is read | Reliability               |
| 6   | Reconcile Krka with the audited annual report, quote it word for word, and replace the Wikipedia citation with the company's own pages                                                                                                        | Removes the weakest evidence in the sample                                                   | Content                   |

## Verdict

**Iterate, then ship.** The site and the engine are built, tested and accessible, and the gate is what makes the engine safe to run: nothing reaches a reader without a quotation behind it. But the engine has not yet met a real filing. Open it to a closed beta (access codes) after fix 1 and with fix 2; fixes 3 and 4 belong in the public launch.
